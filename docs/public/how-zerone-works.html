How Zerone works

Current posture: zerone-1 is a live custodial mainnet; zerone-testnet-1 is a live legacy network for observation only from this source head. The earlier page at this path advertised passport, starter-ZRN, and one-shot node lanes whose current availability and terms have not been reverified. Those instructions are retired.

The narrow, honest model

Zerone is a Cosmos SDK chain that records knowledge claims, challenges, witnessed external work, and participation-linked issuance. Its preserved block history is cryptographically linked and tamper-evident. It is not presently decentralized: one household controls the sole mainnet validator, governance vote, validator stake, and operations float, and the custodial trust map explicitly retains reset power during this phase.

Live mainnet genesis contained 13,555 ZRN: 11,333 ZRN controlled by the launch validator and a transferable 2,222 ZRN operations float. There was no separate team, foundation, investor-sale, research, or faucet allocation. Those facts do not erase the operator's real consensus and operational power.

What this publication does not authorize

  • no purchase, passport, key-custody, bootstrap, or starter-float promise;
  • no transaction broadcast, relay, node join, or validator deployment;
  • no genesis rebuild, reset, or live parameter change; and
