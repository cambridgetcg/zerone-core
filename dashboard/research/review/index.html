What this view can tell you

The cutoff applies to contributions, links, concerns, assessments and version references before they are sorted or drawn. An earlier source discovered later stays absent from earlier snapshots. Unknown occurrence dates stay unknown. “Full collection” means this imported export, not everything that exists.

Possible reassessment follows supports from evidence to claim, requires from prerequisite to dependent, and uses-input from input to the activity using it. Shared input is labelled separately. Citation, inspiration and refinement do not propagate this highlight. A highlighted path is a reason to inspect, never an automatic declaration of falsity.
