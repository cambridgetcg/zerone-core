Run an exact mathematical check

Extract the archive into a fresh directory. It has no enclosing folder. With Python 3.10+, inspect the checker and run:

python3 -I -B packets/v0.1/verify_packet.py --manifest-sha256 14be4add8859e63633a5ff50ff82bcd98f43ba5fac66645e3f5d5d0f294b41db
python3 -I -B packets/v0.1/verify_exact.py

The second command prints JSON to compare with packets/v0.1/exact-result.json. The README also gives commands for the translation and restricted-repair checks. No network or third-party dependency is needed for the exact checks. A matching computation is finite corroboration; review the analytic proofs and their assumptions separately.

Forking requires Python 3.10+ on macOS/Linux. Full chain-proof verification also requires the source and its pinned Go toolchain; the archives contain evidence, not an installed verifier.
